# Security policy

## Reporting a vulnerability

Please report a security problem **privately**, not in a public issue:

1. Open [Security > Report a vulnerability](https://github.com/udienz/quranweb/security/advisories/new) in this repository.
2. Say what you found, how to reproduce it, and what it could allow. A page address and the steps are usually enough.

Only the maintainers see the report. We will answer as soon as we can, tell you whether we agree it is a problem, and credit you
in the fix if you wish. This is a small project run by volunteers, so please be patient; we do not promise a fixed response time.

## What is in scope

The code in this repository and the sites that run it (https://quranweb.udienz.web.id and the test site): sign-in and sessions,
the account data and its export and deletion, the admin page, and the handling of what readers send.

## Please do not

- read, change or delete other people's data, or keep data you reach by accident;
- run denial-of-service tests, scans at a large scale, or anything that slows the site for readers;
- use social engineering or physical attacks.

## Not a security problem

A mistake in the text of the Qur'an, a translation or a tafsir is not a vulnerability: please open a normal issue. The content
comes from published sources and is never edited in this project (see the About page).

## Supported versions

Only the latest release, which is the one running on the site.
